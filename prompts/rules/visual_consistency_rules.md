# Visual Consistency Rules

Use for scene visuals, image/video prompts, cover prompts, avatar visuals, and render-facing visual metadata.

## Blocking

- Do not request readable or unreadable generated text, fake writing, random glyphs, typography, subtitles, captions, logos, UI, watermarks, labels, signs, maps, diagrams, charts, documents, newspapers, plaques, inscriptions, placards, or speech bubbles from image/video models.
- If the real-world subject normally contains writing, labels, plaques, signs, maps, diagrams, screens, or documents, replace them with blank unmarked surfaces or non-text visual evidence.
- Scene 1 title-card text is renderer metadata only; the generated visual prompt remains text-free.
- Scenes after scene 1 must not carry a face-image title unless a future contract explicitly allows it.
- Do not request real-person likeness, brand marks, or protected visuals without explicit rights/consent.

## Must

- Every visual prompt needs a concrete subject, action/situation, setting, composition, and story-specific beat.
- Preserve continuity for recurring subjects, palette, lighting, camera language, and mood.
- Keep visuals vertical-first and mobile-readable.
- Respect director/style-pack constraints without violating safety.

## Should

- Avoid generic symbolic filler when a concrete safe visual can carry the beat.
- Keep cover images aligned with the same visual language as the Reel.

## Preference

- Default to realistic, cinematic, uncluttered vertical compositions.
